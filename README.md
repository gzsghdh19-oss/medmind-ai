# MedMind AI

Flutter starter project for an intelligent medical study assistant.

## Included
- Attractive futuristic medical welcome screen
- Arabic, French and English selection
- Home dashboard
- AI chat placeholder
- PDF study placeholder
- Quiz placeholder
- Flashcards placeholder
- Codemagic Android build configuration

## Next implementation steps
Connect Gemini, implement PDF upload and processing, persistence, authentication,
QCM generation, flashcards, and study history.

Important: Never place unrestricted production API keys directly in a public mobile app.
